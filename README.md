# API магазина продуктов на Django Rest Framework.

## Описание проекта
Данный проект представляет собой REST API для магазина продуктов, разработанный с использованием Django Rest Framework. API позволяет получать информацию о категориях, подкатегориях и продуктах магазина, а также работать с корзиной покупателя. Проект может использоваться как backend-часть интернет-магазина, мобильного приложения или учебного сервиса для демонстрации работы с товарами, категориями, изображениями, авторизацией и корзиной.
В проекте реализовано разделение доступа:
- категории и продукты доступны для просмотра любому пользователю;
- корзина доступна только авторизованному пользователю;
- каждый пользователь может работать только со своей корзиной;
- управление категориями, подкатегориями и продуктами выполняется через Django Admin.

## Основные возможности
Проект реализует следующий функционал:
- просмотр списка категорий с вложенными подкатегориями;
- просмотр списка продуктов с пагинацией;
- хранение категорий, подкатегорий и продуктов в базе данных;
- создание, редактирование и удаление категорий через админку;
- создание, редактирование и удаление подкатегорий через админку;
- создание, редактирование и удаление продуктов через админку;
- привязка подкатегории к родительской категории;
- привязка продукта к подкатегории и категории;
- загрузка изображений для категорий, подкатегорий и продуктов;
- автоматическое создание изображений продукта в трёх разных размерах;
- добавление продукта в корзину;
- изменение количества продукта в корзине;
- удаление продукта из корзины;
- просмотр состава корзины;
- подсчёт общего количества товаров в корзине;
- подсчёт общей стоимости товаров в корзине;
- полная очистка корзины;
- авторизация пользователей по токену;
- документация API через Swagger;
- загрузка тестовых данных через фикстуры;
- автотесты для проверки GET и POST методов.

## Технологии
- Python
- Django Rest Framework
- DRF Token Authentication
- Swagger
- Pillow
- SQLite для локального запуска

## Установка и запуск локально
```bash
python -m venv venv
```

### Windows
```bash
venv\Scripts\activate
```

### Linux / macOS
```bash
source venv/bin/activate
```

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Миграции
```bash
python manage.py migrate
```

### Создание администратора
```bash
python manage.py createsuperuser
```

### Загрузка фикстур
```bash
python manage.py loaddata ingredients.json
```

### Запуск сервера
```bash
python manage.py runserver
```

## Админка доступна по адресу:
```
http://127.0.0.1:8000/admin/
```
Через админку можно создавать, редактировать и удалять:
- категории;
- подкатегории;
- продукты;
- корзины и позиции корзины.

## Swagger доступен по адресу:
```text
http://127.0.0.1:8000/api/docs/
```

OpenAPI schema:
```text
http://127.0.0.1:8000/api/schema/
```

## Запуск тестов
```bash
python manage.py test
```
